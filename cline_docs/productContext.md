# Product Context

## Purpose

This VS Code extension provides context information about the VS Code environment to Language Models, enabling them to better understand and interact with the development environment.

## Problems Solved

1. Enables Language Models to access VS Code terminal information
2. Provides structured access to VS Code's internal state
3. Bridges the gap between Language Models and the development environment

## Expected Behavior

- Extension should provide accurate terminal information when requested
- Information should be properly formatted for Language Model consumption
- Terminal state changes should be reflected in real-time
- Tool should be easily discoverable and usable by Language Models
